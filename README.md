# Zepto Data & AI Guild — Connected AI/ML Platform
### Capstone Project Submission

This repository contains a unified, three-module platform developed for Zepto's analytics guild, fully merged into the `main` branch. It integrates data engineering, predictive modeling, and grounded GenAI services within a single repository.

---

## 1. Project Setup & Installation

A single consolidated `requirements.txt` at the root prevents dependency conflicts and provides a clean initialization.

---

## 2. End-to-End Execution Guide

* **Module 1: Data Engineering (`/data_pipeline`)**
* **Module 2: Analytics & Predictive Pipeline (`/analytics`)**
* **Module 3: GenAI Support Assistant (`/support_assistant`)**

---

## 3. Core Design Decisions

The platform uses robust validation, grouped median imputation, and local token-overlap vector lookups for optimal performance.
